# Photo Editor
A simple web-based photo editor built with React. Users can upload an image, apply various filter effects, adjust them using sliders, compare before/after versions, and download the edited image.

You can try the live version of the Photo Editor here: [Photo Editor Live](https://beatrixvv.github.io/photo-editor/).


## Features
* Upload Image:\
Select an image from your device to edit.

* Filter Adjustments:\
Modify brightness, contrast, saturation, grayscale, hue rotation, inversion, opacity, sepia, and blur.

* Live Preview:\
See real-time changes as filters are adjusted.

* Reset Filters:\
Restore filters to their default values.

* Compare Mode:\
Toggle between the original and edited image.

* Download Image:\
Save the edited image as a PNG file.


## Installation

1. Clone the repository:
```bash
git clone https://github.com/beatrixvv/photo-editor.git
cd photo-editor
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm start
```


## Usage
* Click "Upload Image" icon to select an image from your device.

* Choose the desired filter and use the sliders to adjust the intensity.

* Click "Reset" to restore filters to default values.

* Hold the "Compare" button to toggle between original and edited image.

* Click "Save" to download the edited image.


## Technologies Used
* React.js

* HTML-to-Image (for saving edited images)

* FontAwesome Icons
